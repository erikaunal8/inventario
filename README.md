# 📦 Sistema de Gestión de Inventario — Ferretería Rubén Guerrero

Aplicación de línea de comandos en **Python** para gestionar el inventario de una ferretería real, con persistencia de datos en **SQLite**.

Este proyecto nace de una necesidad concreta: digitalizar y automatizar el control de stock de un negocio familiar, sustituyendo el registro manual en papel/Excel por una herramienta propia.

---

## 🎯 ¿Qué problema resuelve?

La ferretería necesitaba una forma sencilla de:
- Consultar qué productos hay en stock y en qué cantidad
- Registrar entradas y salidas de material
- Evitar errores de conteo manual
- Tener una base sobre la que construir, en el futuro, una web de consulta para el negocio

---

## 🛠️ Tecnologías

- **Python 3** — lógica de negocio y funciones de inventario
- **SQLite** — base de datos local, ligera y sin necesidad de servidor
- **sqlite3** (librería estándar de Python) — conexión y consultas a la base de datos
